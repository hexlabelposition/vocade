# Vocade

Продиктуй цифры по-русски, получи Code128 или QR. Распознавание полностью в браузере (Vosk + WASM), работает офлайн как PWA.

## Запуск

```bash
npm install
npm run fetch-model   # один раз: скачивает русскую модель Vosk (~45 МБ) в public/models
npm run dev           # http://localhost:5173
```

С телефона в локальной сети: `npm run dev:https` и открыть `https://<ip-ноутбука>:5173` (принять самоподписанный сертификат). Без HTTPS браузер не даст доступ к микрофону.

Прод: `npm run build`, папку `dist` залить на любой статический хостинг с HTTPS. После первого открытия модель лежит в кэше service worker'а, дальше всё работает без сети.

Деплой: push в `main` запускает `.github/workflows/deploy.yml` (модель качается в CI и кэшируется), сайт публикуется на https://hexlabelposition.github.io/vocade/. Base path задан в `vite.config.ts` (`base: '/vocade/'`), при переименовании репозитория его нужно поменять.

## Как диктовать

Распознаются только числительные (через grammar), поэтому точность для цифр высокая. Можно по одной цифре («четыре шесть ноль семь») или числами («сорок шесть ноль семь»), оба варианта дадут `4607`. Поле редактируется руками, если что-то распозналось не так.

`npm test` проверяет парсер числительных.

## Структура

- `src/numbers.ts`: слова в цифры + словарь для grammar
- `src/speech.ts`: микрофон и Vosk (грузится отдельным чанком)
- `src/main.ts`: UI, JsBarcode (Code128), qrcode
